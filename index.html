Production integration

Backend API contract

Edit only the marked VIKAS_BACKEND_CONFIG block near the bottom of this HTML. The server may use any database.

GET /healthReturns { "ok": true } for connection monitoring.
GET /paymentsReturns an array or { "payments": [...] }.
POST /paymentsCreates a payment record after server-side validation and duplicate checks.
PATCH /payments/:id/verifyBody: { "status": "APPROVED" | "REJECTED" }. The backend must reject all later changes.
GET /payment-configReturns category fee and seat configuration.
PUT /payment-configSaves authenticated fee and capacity settings.
window.VIKAS_BACKEND_CONFIG = { baseUrl: "https://YOUR-BACKEND-DOMAIN.com/api", databaseProvider: "YOUR_DATABASE", authMode: "bearer", tokenStorageKey: "vikas_admin_token", pollIntervalMs: 30000 };
Security: keep database passwords, service-account keys and payment-gateway secrets on the backend. Do not paste them into this file. Authentication and immutable verification must be enforced by the server.
